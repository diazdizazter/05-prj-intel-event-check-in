# Intel Sustainability Summit: Event Check-in App

To get started, create a new Codespace from this repo.
Project 5 | Intel Summit Check-In
. a company-wide Sustainability Summit focused on reducing emissions, conserving water, and building a more sustainable future.
Intel employees have been grouped into three teams based on sustainability goals, and they'll compete to see which team has the highest turnout.
Your task: build a check-in app to welcome attendees, track participation, and tally team turnout.

Project Steps Overview:
Click this starter file link to launch your own Codespace.

Greet Attendees on Check-In:
Capture attendee names from the provided input field.
Dynamically display a personalized greeting message each time someone checks in.
Implement Attendance Counting:
Track and update the total number of attendees.
Display the updated count each time an attendee checks in.
Team Attendance Tracker:
Track the number of attendees for each team:

Team Water Wise
Team Net Zero
Team Renewables
Update and display each team's total count based on attendees' selected teams.
Progress Bar:
Update the provided attendance progress bar as attendees check in.
Indicate progress toward the attendance goal (for example, 50 attendees).
Ready for a LevelUp? (25pts extra credit)
Celebration Feature  (5 pts): When the attendee check-in goal is reached, display a celebration message highlighting the winning team's name.
Save Your Progress (10 pts): Save the total attendance count and individual team counts to the browser's local storage. Ensure counts persist even if the user refreshes or closes and reopens the page.
Attendee List (10 pts): Display the list of attendee names and their teams beneath the team counters, closely matching the provided design.
